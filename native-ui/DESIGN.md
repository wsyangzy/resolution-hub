# 原生界面设计约束

## 模块和状态

`core` 负责显示、进程、启动与持久化，界面通过 StatusSink 获取会话通知。
`native-ui` 负责 Slint 呈现、用户草稿、后台任务与原生窗口；不复制运行状态机。
主窗口和浮层使用两个 AppWindow，共享一个 Controller、AppState 和 RuntimeManager。
浮层是独立 owner 窗口，用于承载工作条边界之外的内容，不使用宿主内 PopupWindow。

Operation 控制后台任务期间的按钮和关闭行为；识别取消与会话取消使用各自代次。
状态读取失败仍保留恢复保护，不能用空值或默认 idle 放行启动和关闭。
所有后台结果通过 Slint 事件循环更新组件，持锁期间不调用可能等待其他线程的系统操作。

## 布局

工作条固定 688×56 逻辑像素；应用窗口初始宽 860px，高度按内容在 320～680px 内确定，
常规最小尺寸 660×320px。布局受当前显示器工作区与 DPI 夹紧。
普通缩放事件尊重用户尺寸，只有布局切换才重新应用默认约束。

浮层先按物理像素确定宽度，再读取排版后的内容高度，防止非整数 DPI 的换行振荡。
工作条下方不足时向上展开，应用窗口浮层居中；长表单内部滚动，底部操作保持可见。
窗口几何事件合并调度，不将浮层自身定位事件递归当作新的布局请求。

基础控件使用现有 Fluent 风格尺度：常规高 36px、紧凑高 32px、圆角 6px。
标题、图标按钮和表单操作行显式垂直居中。焦点使用内部 2px 描边，鼠标设焦与初始设焦不显示键盘描边。
Space/Enter 松开仅激活一次，失焦或禁用会清除按压状态。

## 列表、图标和更新

游戏库保留可见行和缓冲；来源与候选列表使用 Slint 1.17 原生 ListView 重复器。
本地适配器必须保留框架识别所需的五个属性，升级 Slint 后在 CI 生成代码中复核
`ensure_updated_listview`，不能退化为实例化整个目录的普通重复器。
来源行步长 48px、卡片高 46px，使用固定几何与文本省略，交互颜色即时反馈。
选择回传目录条目的原始 index，过滤后不能用可见行号替代。

目录、来源、搜索和选择按修订号缓存模型。单次输入只更新当前编辑器，隐藏面板不重复构建。
图标请求按来源有效字段和 Windows 路径大小写去重，成功/失败均缓存。
后台解码限制尺寸和内存，保留真实透明度；Slint Image 留在 UI 线程，只更新匹配行。

## 动效和输入保护

Motion 统一管理反馈 120ms、按压 65ms、展开 180ms、收起 100ms。
浮层目标尺寸的透明起点实际完成绘制后再进入，轻移 8px；向上展开时反转方向。
绘制通知不可用时有计时回退，进入与退场共用代次保护，旧回调不能隐藏新打开的浮层。
不逐帧调整原生窗口几何，高级区只在内容高度变化时重新测量。
Windows 关闭动画效果时所有时长归零，弹窗退场期间继续阻止背景输入。

浏览类面板在主窗口和浮层都失焦后关闭，新增、识别和确认保留以支持切换到外部启动器。
主窗口关闭经过受保护的退出流程；浮层关闭只处理面板、识别取消或草稿确认。
恢复失败必须保留窗口与恢复入口。

## 性能与验收

状态读取、文件访问、进程识别、图标与偏好写入使用后台队列，空闲时阻塞等待而非轮询。
合并重复运行通知，修订号丢弃过期结果；不通过高频刷新制造流畅效果。
默认不创建诊断日志线程，手动开启才使用有界队列记录采样。

具体采样命令和指标限制见 [README](README.md)。CI 检查格式、测试、构建和 EXE 资源，
真实首次绘制、滚动流畅度、DPI、关闭和显示模式切换由用户在 Windows 中验收。
